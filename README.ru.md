# Генератор персонажа для Cyberpunk RED

**Соберите персонажа Cyberpunk RED за несколько минут прямо в браузере. Без регистрации, без
установки, работает и без интернета.**

**[▶ Открыть онлайн](https://cellpot.github.io/cpr-character-generator/)** · [English version](README.md)

Хотите держать у себя? Скачайте `generator.html` (кнопка скачивания на странице файла) и
откройте в любом браузере. Это один файл, интернет ему не нужен.

---

## Что он умеет

Мастер ведёт по созданию персонажа из корбука шаг за шагом:

**Роль → СТАТы → Навыки → Жизненный путь → Снаряжение → Стиль → Лист персонажа**

- **Все три метода создания** из книги: №1 «Уличная крыса», №2 «Эджраннер» и
  №3 «Полный пакет».
- **Бросает за вас или даёт решить самому.** Можно бросить одну строку Жизненного пути,
  бросить всё сразу или вписать значения вручную.
- **Считает за вас.** ПЗ, порог ранения, спасбросок, Человечность (с учётом стартовых
  имплантов), ролевая способность на ранге 4, стартовые деньги.
- **Снаряжение из каталога** корбука и дополнений: цены и страница, где предмет описан.
- **Отсылает к книге.** У каждого правила есть чип со страницей — «КБ 144» (корбук) или
  «BC 9» (Black Chrome), так что спорный момент проверяется за одно обращение к книге.
- **Русский и английский**, переключатель прямо на странице; при первом запуске страница
  берёт язык браузера. Четыре оформления: День, Ночь, Кибер и Авто.
- **Приватно.** Персонаж хранится в вашем браузере и никуда не отправляется.

## Заберите персонажа с собой

| Кнопка | Что получится | Для чего |
|---|---|---|
| **Печать / PDF** | печатный лист | отдать мастеру или принести за стол |
| **Скачать .md** | заметка в Markdown (таблицы, навыки по убыванию броска) | хранилище заметок вроде Obsidian |
| **Сохранить .json** / **Загрузить .json** | ваши выборы и броски | продолжить позже или перенести на другое устройство |

Что полезно знать:

- В окне печати выбирайте «Сохранить как PDF» самого браузера. Виртуальный принтер Windows
  «Microsoft Print to PDF» сохраняет страницы картинками, и текст в таком файле нельзя ни
  выделить, ни найти.
- Файл .md называется по имени персонажа: не кладите его поверх уже написанной заметки с тем
  же именем.
- В .json лежат ваши *выборы*, а не готовый лист. После обновления генератора загруженный
  персонаж пересчитывается по новым данным.
- Загруженный файл проверяется: лишнее отбрасывается, а повреждённый файл не открывается и
  текущего персонажа не меняет.

## Это не замена книге

Это инструмент, а не свод правил. Здесь механика, таблицы и краткий пересказ своими словами,
и всегда указано, на какой странице книги правило изложено полностью. Если игра нравится,
купите официальные книги.

## Собрать самому

```
python build.py        # → generator.html; только стандартная библиотека Python 3
```

`generator.html` — готовая страница; она лежит в репозитории, чтобы её можно было скачать и
пользоваться как есть. `build.py` пересобирает её из `src/`, `data/` и `texts/`.

`data/` (СТАТ-шаблоны, наборы навыков, таблицы, каталог снаряжения) экспортируется из
отдельного закрытого проекта, где данные извлекаются и сверяются с книгами, поэтому здесь
руками не правится, а `build.py` его не создаёт. `texts/summaries.json` — наши собственные
краткие формулировки, которыми заменён текст книги.
